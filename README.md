# RedTeaming
Cybercon 2026 AI Red Teaming workshop

**Workshop Preparation**. 
To prepare for participating in the workshop, you should register and get an API key from Google as below.  
Ensure you are logged into your google account on your browser (use your own gmail account or create a temporary one for the workshop).
To obtain a Google API key navigate to https://aistudio.google.com and go to the left hand menu API Keys. Copy the default API key (or create a new one) and store it as a command line environment variable.

**Linux & Mac Terminal**. 
export GOOGLE_API_KEY=AIz………………

**Windows Command Line**
set GOOGLE_API_KEY=AIz………………
